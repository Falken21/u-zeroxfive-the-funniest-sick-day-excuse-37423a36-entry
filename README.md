A one-line sick-day text written the way a real person would send it. On
the surface it is half believable — the sender really is ill — but one
layer down the roles flip: the immune system is the one who called in
sick, and the sender is merely staying home to cover its shift. The joke
lands on the final words, and at 122 characters nothing in the line is
wasted.

## The entry

> Morning boss, can't come in today. My immune system called in sick before I could, so I'm staying home to cover its shift.

122 characters.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` with no trailing newline.
